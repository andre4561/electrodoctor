# Болезненность живота

При лёгком и чуть более глубоком нажатии: больно ли, где именно (верх/низ, справа/слева).

Нет боли — слева; умеренная локальная — середина; резкая, не можете терпеть касание — справа. При острой сильной боли не продолжайте самоосмотр — нужна помощь.
