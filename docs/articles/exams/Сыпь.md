# Сыпь

Есть ли высыпания на коже сейчас. Если да — где (лицо, туловище, руки, ноги), примерно сколько (единичные / пятно зоны / почти везде).

Вид: плоские пятна, бугорки, пузырьки, гнойнички, «волдыри» как от крапивы, сливаются ли.

Зуд, жжение, когда появились, после чего (еда, лекарство, жара) — если знаете.
