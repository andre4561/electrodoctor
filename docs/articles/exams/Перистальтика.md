# Перистальтика

Это работа кишечника: урчание, газы, стул. Положите ладонь на живот на минуту — есть ли урчание, видно ли движение.

Напишите: обычное урчание / очень бурное / тишина и вздутие; когда был последний стул, если это важно для жалобы.

«Выслушивание чашечкой» без навыка можно не делать.
