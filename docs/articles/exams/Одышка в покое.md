# Одышка в покое

Сидите спокойно минуту: дышится свободно или воздуха не хватает без ходьбы и подъёма по лестнице.

Нет ощущения нехватки воздуха — слева; тяжело говорить фразами, помогают плечи/шея при вдохе — правее; задыхаетесь в покое — у правого края.
