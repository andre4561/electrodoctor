# Деформация / осанка

Встаньте боком и спиной к зеркалу (или фото в профиль/со спины): сутулость, боковой изгиб, одно плечо выше, «косолапость», кривизна пальцев.

Есть ли контрактура (сустав не разгибается до конца).

Опишите, что видно.
