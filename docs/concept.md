## Принципы

- **Расчёт без нейросети.** Цифры на входе, явные формулы, вероятность на выходе. Один и тот же вход всегда даёт один и тот же результат.
- **Объяснимость.** Для каждого диагноза видно, какой показатель сколько добавил или отнял.
- **Данные у пациента.** Клиент хранит историю у себя и отправляет на сервер обезличенную таблицу. Сервер ничего не хранит.
- **ИИ только вокруг расчёта:** помощь при сборке справочника и объяснение результата пациенту.

## Шаг 1. Критичность показателя

```
d = ln(x / x0)
сила = max(0, |d| − w) / scale
k = a · сила²        a = a_low при d < 0, a_high при d > 0
```

Логарифм уравнивает «в N раз меньше» и «в N раз больше». Зона `w` — плоское дно параболы (норма). `a_low` и `a_high` задают разную опасность падения и роста.

Знак `d` (направление) идёт в расчёт диагнозов, `k` — в красные флаги.

Для жалоб и осмотра: да/нет → сила 0 или 1; шкалы → значение / максимум шкалы.

## Шаг 2. Направления («терапевт → специалисты»)

Диагнозы распределены по направлениям (`data/directions.csv`), один диагноз может быть в нескольких. Отсечение мягкое: открывается несколько самых весомых направлений, и анализы тоже могут открыть направление. В эталонной реализации пока считаются все диагнозы (см. roadmap).

## Шаг 3. Вклады и вероятность

| Ситуация | Вклад |
|---|---|
| отклонение в ожидаемую сторону | +вес × сила |
| отклонение в обратную сторону | −вес × сила |
| показатель в норме / признака точно нет | штраф |
| показатель не измеряли / не спрашивали | 0, попадает в «что досдать» |

```
балл = ln(p0 / (1 − p0)) + Σ вкладов
P = 1 / (1 + e^(−балл))
```

`p0` — исходная частота диагноза в целевой группе. Математически это логистическая регрессия, поэтому веса можно уточнять на данных.
