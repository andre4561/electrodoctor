# Как открыть сайт

Папка `docs/` — это сайт, но в браузере он сам не работает.
Сначала нужно поднять локальный сервер.

## Самый простой способ

Дважды щёлкните файл **`открыть-сайт.bat`** в корне проекта.

Он запустит сервер и откроет главную страницу:
http://localhost:8000/

Окно с чёрным текстом не закрывайте — пока оно открыто, сайт доступен.
Чтобы остановить сервер, закройте это окно или нажмите Ctrl+C.

## Вручную, из терминала

В корне проекта (`D:\electrodoctor`) выполните:

```bash
python tools/preview.py
```

Потом откройте в браузере: http://localhost:8000/

Кабинет: http://localhost:8000/app/#/clients

Если порт 8000 занят:

```bash
python tools/preview.py 8080
```

и откройте http://localhost:8080/

## Замечание

Один раз может понадобиться пакет `markdown`:

```bash
pip install markdown
```

Не открывайте `docs/index.html` или кабинет напрямую как файл с диска —
кабинет с `file://` не загрузится.
