# Щитовидная железа

Щитовидка лежит спереди на шее ниже кадыка. Встаньте перед зеркалом, слегка запрокиньте голову, сделайте глоток воды — смотрите, есть ли асимметрия или выпячивание.

Осторожно пальцами по бокам от кадыка (не давите сильно): есть ли уплотнения, боль, «узелки».

Напишите: ничего необычного / видно увеличение / нащупывается узел (примерно где).
