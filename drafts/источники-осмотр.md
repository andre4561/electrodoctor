# Откуда брать материалы для статей осмотра

Задача не «придумать разделы», а **пересказать и упростить** уже существующие
карты осмотра с авторитетных площадок. Ниже — что лучше брать и на какие
признаки нашего каталога это ложится.

Предыдущий файл `шаблон-осмотр.md` — черновая раскладка разделов; **структуру
статьи лучше выводить из источника**, а не навязывать одну схему всем признакам.

## Главный принцип

| Слой | Зачем |
| --- | --- |
| Русская пропедевтика (вузы) | Термины и приёмы как в отечественной клинике (Пастернацкий, Образцов–Стражеско…) |
| Английские OSCE-гайды | Пошаговые «карты» с чеклистом: куда встать, что смотреть, что писать |
| NCBI / StatPearls, официальные шкалы | Точечные техники и шкалы (лёгкие, GCS…) |
| КР Минздрава / MedElement | Не методика осмотра целиком, а когда признак упоминается в стандарте |

Лицензии разные: при переносе — **пересказ своими словами** + ссылка в `source`
шапки статьи; дословные куски учебников и Bates не копировать.

## 1. Русская база (термины и классические приёмы)

**Лучше всего для «как принято у нас»:**

1. **Самарский ГМУ — пособие по методам исследования** (открытый PDF)  
   https://www.samsmu.ru/files/smu/chairs/propedtherapy/propedevtika_vb.pdf  
   Осмотр / пальпация / перкуссия / аускультация по системам. Удобный каркас
   под группы кабинета: дыхание, сердце, живот, моча, общий вид.

2. **РНИМУ им. Пирогова — схема истории болезни / методика ребёнка**  
   - https://rsmu.ru/fileadmin/templates/DOC/Faculties/PF/Dept_of_faculty_therapy/Skhema_istorii_bolezni._Pojasnenie.pdf  
   - https://rsmu.ru/fileadmin/templates/DOC/Faculties/PF/Dept_pdb/pdb/Polnaja_metodika_issledovanija.pdf  
   Списки «что смотреть» по системам (почки, симптом Пастернацкого, кожа…).

3. **Сеченовский университет — перечень практических навыков пропедевтики**  
   https://www.sechenov.ru/univers/structure/institute/institut-klinicheskoy-meditsiny/kafedry-klinicheskoy-mediciny-im-Sklificovskoro/propedevt/spisok-voprosov-i-prakticheskikh-navykov-dlya-ekzamena/  
   Чеклист навыков (что студент обязан уметь) — сверка, что мы ничего важного
   не выкинули из каталога.

4. **Канон в библиотеке (платно / через вуз), не скрейпить целиком:**  
   Мухин Н.А., Моисеев В.С. *Пропедевтика внутренних болезней* (ГЭОТАР).  
   Эталон формулировок; для статей — только сверка и пересказ.

**Сюда же:** учебные PDF кафедр пропедевтики других вузов (Саратов и др.) —
как доп. при расхождении методик (например, поколачивание кулаком vs ребром
ладони).

## 2. Английские «карты» осмотра (шаги и чеклисты)

Именно это ближе всего к «на сайтах уже лежат карты».

1. **Geeky Medics — OSCE guides** (бесплатно читать)  
   https://geekymedics.com/  
   Примеры:  
   - дыхание https://geekymedics.com/respiratory-examination-2/  
   - живот https://geekymedics.com/abdominal-examination/  
   - неврология конечностей / черепные нервы  
   Формат: подготовка → осмотр → пальпация → … → находки. Идеально как
   **скелет статьи** + перевод/адаптация под самооценку.

2. **LITFL Clinical Examination database**  
   https://litfl.com/clinical-examination-database/  
   Указатель бесплатных видео/разборов по системам + **Stanford 25**
   (печень, селезёнка, лимфоузлы, щитовидка, зрачки, лёгкие…).  
   Удобно, когда нужна **одна конкретная** манипуляция, а не весь OSCE.

3. **Stanford Medicine 25** (через LITFL или напрямую)  
   Короткие эталонные демонстрации «как делают у постели».

4. **Bates’ Guide / Bates’ Visual Guide** (Wolters Kluwer) — золотой стандарт,
   но **платный**. Имеет смысл как эталон, если есть доступ; в открытый текст
   проекта не копировать.

## 3. Точечные техники и шкалы

1. **NCBI Bookshelf / StatPearls** (открыто)  
   - общий осмотр: https://www.ncbi.nlm.nih.gov/books/NBK361/  
   - лёгкие: https://www.ncbi.nlm.nih.gov/books/NBK459253/  
   - GCS: https://www.ncbi.nlm.nih.gov/books/NBK513298/  
   Хорошо для дыхания, отдельных приёмов, ссылок.

2. **Официальная ШКГ**  
   https://www.glasgowcomascale.org/  
   Русская инструкция:  
   https://www.glasgowcomascale.org/downloads/GCS-Assessment-Aid-Russian.pdf  
   Плюс приложения к КР Минздрава (инсульт и др.) — для формулировок E/V/M.

3. **MedElement / рубрикатор КР**  
   https://medelement.com/ · https://cr.minzdrav.gov.ru/  
   Не карта осмотра, а **когда** признак входит в стандарт (живот при
   аппендиците, менингеальные знаки при инфекциях ЦНС…). Брать дозировано.

## 3. Карта «наш раздел → куда смотреть первым»

| Группа кабинета | Основной источник | Дополнительно |
| --- | --- | --- |
| Общий вид, сознание, ЧДД, телосложение | СамГМУ PDF + схема РНИМУ | StatPearls / GCS official для ШКГ |
| Кожа, желтуха, цианоз, сыпь | СамГМУ / РНИМУ (общий осмотр) | Stanford 25 / LITFL (язык, ногти — по мере нужды) |
| Лимфоузлы | Stanford 25 Lymph nodes + Geeky (neck) | СамГМУ |
| Голова, зев, глаза, щитовидка | Geeky (ENT/thyroid) + Stanford 25 Thyroid | Сеченов навыки |
| Дыхание, хрипы, перкуссия, одышка | **Geeky Respiratory** + StatPearls Lung Exam | СамГМУ (русские названия шумов) |
| Сердце, тоны, шумы, ритм, отёки, пульс | Geeky Cardiovascular + Stanford 25 | СамГМУ |
| Живот, печень, селезёнка, перистальтика | **Geeky Abdominal** + Stanford 25 Liver/Spleen | СамГМУ (Образцов–Стражеско) |
| Поколачивание, отёки лица | **СамГМУ / РНИМУ / Сеченов** (Пастернацкий) | Wikipedia/учебник — только как указатель, не как база |
| Неврология, Ромберг, сила, зрачки, менингеальные | Geeky neuro + LITFL Romberg + GCS official | КР по инфекциям ЦНС / инсульту |
| Суставы, объём движений, осанка | Geeky MSK / GALS + LITFL MSK videos | — |
| Локальный статус / прочее | По ситуации: хирургические КР (MedElement) | Geeky по зоне |

## 4. Чего лучше не брать за основу

- Случайные блоги, курсовые на studfile без кафедры и года.
- Википедия — только для имени симптома и ссылок дальше.
- MedElement **вместо** пропедевтики: там болезнь и тактика, не пошаговый осмотр.
- Платные Bates/видео — не выкладывать чужой текст/кадры в репозиторий.

---

## 5. Как писать статью из источника (когда скажешь «переписывай»)

1. Выбрать **один основной** источник из таблицы выше + один русский для терминов.
2. Выписать шаги и находки.
3. Пересказать простым языком под самооценку (без назначения лечения).
4. В шапке `source:` указать URL/название пособия.
5. Края шкалы (`from`/`to`) оставить согласованными с каталогом.

Объём: полно, но без простыни учебника — цель та же, что у Geeky-страницы:
после прочтения понятно, **как сделать** и **что считать отклонением**.
