# Сюда кладут заключения аудита

ИИ-аудитор по инструкции из корневого `AUDIT.md` создаёт файл вида:

`YYYY-MM-DD-<кратко>.md`

по шаблону `../REPORT_TEMPLATE.md`.

Человек потом открывает этот файл в IDE и правит проект по находкам
(сначала `critical` и `high`). Сами отчёты можно коммитить — в них не должно быть секретов.
