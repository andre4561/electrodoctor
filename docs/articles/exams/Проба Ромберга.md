# Проба Ромберга

## Что это

Проба Ромберга (стойка Ромберга) — классический элемент неврологического осмотра, оценивающий **сенситивную (проприоцептивную) атаксию**. При поражении задних столбов спинного мозга или периферических больших афферентов пациент плохо чувствует положение стоп на опоре; зрение компенсирует дефект — с открытыми глазами устойчивость относительно сохранна, с закрытыми — появляется или усиливается шатание и риск падения.

Важно не путать:

| Паттерн | Типичная интерпретация (для записи) |
|---------|-------------------------------------|
| Шатание **только** с закрытыми глазами | Позитивная проба Ромберга → сенситивный компонент |
| Шатание **уже** с открытыми глазами | Вестибулярная или мозжечковая атаксия; проба Ромберга может быть отрицательной |
| Не может стоять без опоры вообще | Тяжёлая слабость, парез, нестабильность — пробу не форсируйте |

Положительный результат **не означает** конкретный диагноз (дефицит B12, сифилис, диабетическая нейропатия и др. входят в дифференциальный ряд) — фиксируется только поведение при стоянии.

## Подготовка

- Ровная твёрдая половица без ковра, который скользит; **обязательна опора** — спинка стула, стена, стол или рядом стоящий человек.
- Босиком или в нескользкой обуви; пятки вместе, носки слегка разведены (классика) либо стопы на ширине плеч, если так устойчивее — укажите в записи.
- Освободите пространство 1–1,5 м вокруг.
- **Не выполняйте**, если: выраженное головокружение в покое, недавнее падение, острая травма конечностей, низкое давление с головокружением, тяжёлая слабость в ногах, пьянство, приём седативных с нарушением координации.
- Сначала оцените стойку **с открытыми** глазами 20–30 секунд, затем — с закрытыми не дольше 10–15 секунд при наличии страховки.

## Как сделать

1. Встаньте, руки вдоль тела или слегка в стороны (не использовать опору руками, если цель — чистая проба; для безопасности допустим один палец на стене — отметьте в тексте).
2. **Фаза 1 — глаза открыты:** зафиксируйте покачивание, отклонение вперёд/назад/в стороны.
3. **Фаза 2 — глаза закрыты** (по команде «поехали»): наблюдатель готов подстраховать.
4. Сравните: стало ли заметно хуже (больше амплитуда, шаг в сторону, падение).
5. Опишите направление дрейфа: «тяга назад», «влево», «вперёд» — это помогает при последующем разборе.

**Вариант OSCE у постели:** сидя на краю кушетки проба неполноценна; стандарт — стоя.

**Пример записи врача:** «Ромберг: с открытыми глазами лёгкое покачивание; с закрытыми — устойчивое отклонение назад, без падения; дотрагивается до стула».

## Что бывает

| Результат | Как описать |
|-----------|-------------|
| Устойчив с открытыми и закрытыми | Ромберг отрицательный (или «без усиления при закрытии») |
| Лёгкое покачивание только с закрытыми | Слабоположительный / пограничный |
| Выраженное шатание или шаг для коррекции с закрытыми | Ромберг положительный |
| Падение с закрытыми | Резко положительный; осмотр прерван |
| Нестабильность уже с открытыми | Отдельно указать; не сводить только к Ромбергу |
| Головокружение без «точечного» ухудшения при закрытии | Чаще периферический вестибулярный компонент |

## Как отметить в кабинете

Текстовое поле. Минимальный набор:

- Устойчивость **с открытыми** глазами.
- Изменение **с закрытыми** (нет / усилилось / падение).
- Была ли опора, направление дрейфа.
- Прерывали ли пробу по безопасности.

**Примеры:**
- «Стоит ровно с открытыми; с закрытыми — лёгкое покачивание, опора на спинку стула, падения нет»
- «С открытыми — шатание; с закрытыми — шаг влево, Ромберг положительный»
- «Пробу не выполнял: головокружение и слабость в ногах»

## Ограничения

- **Риск падения** — главное ограничение; помощник обязателен пожилым и ослабленным.
- Пожилые могут шататься по иным причинам (ортостаз, остеоартроз коленей), не только сенсорная атаксия.
- Усталость, алкоголь, антидепрессанты искажают результат.
- Одна проба не различает мозжечок и вестибулярный аппарат — нужен комплекс (ходьба, пальценосовая, нистагм).
- Самооценка без третьего лица ненадёжна: падение может быть необнаружено в тексте.

## Кратко

Встаньте, пятки вместе, руки вниз; рядом опора. Сначала с открытыми глазами, затем с закрытыми. Если с закрытыми шатание заметно сильнее — Ромберг положительный. Опишите обе фазы и направление дрейфа. Не делайте пробу при выраженном головокружении или слабости без страховки.
