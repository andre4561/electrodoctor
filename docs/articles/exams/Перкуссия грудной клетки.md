# Перкуссия грудной клетки

Перкуссия — постукивание пальцем по пальцу на грудной клетке; звук сравнивают слева и справа. Без навыка легко ошибиться.

Если не умеете — опишите ощущения: тяжесть, боль в боку при дыхании, «не раздувается» одна сторона — и оставьте пометку, что перкуссию не делали.

Если делали с знающим человеком — напишите, где звук короче или «пустой» по сравнению с другой стороной.
