# Как участвовать

Контекст для агентов и устройство кабинета — [AGENTS.md](AGENTS.md). Форматы JSON —
[docs/data-format.md](docs/data-format.md). Ограничения — [DISCLAIMER.md](DISCLAIMER.md).

## Предложить признаки диагноза

Правки попадают в `docs/data/signs.json` (ключ — имя файла статьи в
`docs/articles/diagnoses/` без `.md`) или предлагаются через конвейер `tools/ai_signs*.py`.

Для каждой пары «диагноз–анализ» укажите:

- код анализа из `docs/data/labs.json` (или название, если кода ещё нет);
- направление `up` / `down` / `any` и важность `w` (0–10);
- по возможности источник (рекомендация, статья, DOI) или пометку экспертной оценки.

В кабинете то же можно править: Настройки → Диагнозы → нужный диагноз (редактор
признаков). Свои правки хранятся в настройках пользователя и перекрывают файл.

## Добавить диагноз

1. Статья Markdown в `docs/articles/diagnoses/` с YAML-тегами специальностей.
2. Раздел в `docs/data/diagnoses.json` появится после `python tools/diagnoses_sections.py`.
3. Признаки — в `signs.json` (вручную или через `tools/ai_signs.py` + merge).

## Добавить анализ в каталог

- В кабинете: Настройки → **Нормы и веса** → раздел материала → «+ Добавить анализ»
  (пишет в настройки пользователя поверх `labs.json`).
- В репозиторий: конвейер `tools/labs_catalog_*.py` / правка сборки; числовым —
  норма в `docs/data/norms.json` (`tools/ai_norms.py` + `norms_apply.py`).

У клиента произвольный новый код создать нельзя — только выбрать из каталога.

## Код кабинета

- Исходники — `src/app/*.ts`. Собранный `docs/app/*.js` — только через `npm run build`;
  коммитьте `.ts` и `.js` вместе.
- Расчёт вероятности — `src/app/signs.ts` (явные формулы, без ИИ внутри).
- Перед PR: `npm test`.

## Чего не присылать

Реальные данные пациентов, даже «обезличенные вручную». Только вымышленные примеры.
Ключи API и `secrets/` — не в git и не в issue/PR.
