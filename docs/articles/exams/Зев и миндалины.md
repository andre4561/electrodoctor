# Зев и миндалины

Встаньте перед зеркалом, откройте рот при хорошем свете, скажите «а-а» (можно придержать язык чистой ложкой — осторожно).

Посмотрите заднюю стенку горла и миндалины по бокам: красные ли, отёчные, есть ли белый/серый налёт, пробки в углублениях, одна миндалина больше другой.

Кратко запишите, что видно и больно ли глотать.
