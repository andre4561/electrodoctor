# Суставы

## Что это

Осмотр суставов — часть опорно-двигательного статуса: фиксируют **внешний вид**, **пальпацию** и **активные движения** с опорой на сравнение с парным суставом и с «эталонной» нормой для пациента. Классическая схема OSCE: **смотрю — наощупь — двигаю** (inspection, palpation, active ROM with pain).

Типичные признаки воспаления (часто по памятке «PRIS» или «боль — эритема — отёк — жар — функция»):

- **Отёк** — выпячивание, сглаженность суставных линий.
- **Гиперемия** — покраснение кожи над суставом.
- **Локальное повышение температуры** — ладонь пациента на здоровом, затем на больном суставе.
- **Болезненность** при движении и в покое.
- **Дефигурация** — изменение оси, подвывих, узелки.

Пункт охватывает **несколько суставов**, а не один: при системном процессе перечисляют все изменённые; при моноартрите — детали одного.

## Подготовка

- Достаточно света; снимите или закатайте рукав/штанину над нужным уровнем.
- Пациент в удобном положении: колени — сидя со свисающими ногами или лёжа; локти — сидя за столом; кисти — на коленях ладонями вниз для симметрии.
- Сравнивайте **правый и левый** и **утро vs вечер**, если утренние скованность и отёк — в жалобах.
- Острая травма (деформация, невозможность нагрузки) — не форсируйте движения, опишите видимое.
- Учитывайте базовый остеоартроз пожилых: узелки ДБЧ, крепитация без воспаления — это тоже «суставы», но другой характер.

## Как сделать

**Обзор (инспекция)**

Обойдите типичные зоны по жалобе и по протоколу скрининга:

| Зона | На что смотреть |
|------|-----------------|
| Плечи | Симметрия контуров, «квадрат» над плечом, опущение ключицы |
| Локти | Отёк, сгибательная / разгибательная складки |
| Кисти, MCP, PIP, DIP | Узелки, вульгус/варус пальцев, отёк «с кисть как целое» |
| Тазобедренные | Симметрия складок, укорочение при эндопротезе/контрактуре — косвенно через длину ног |
| Колени | Опухлость надколенника, атрофия бедра, варус/valgus |
| Голеностопные, стопы | Отёк, подагрические тофусы, плоскость свода |
| Шея (функция) | Скованность отдельно в «объём движений»; здесь — отёк шейных суставов редко, но боль в паравертебральных точках могут описать |

**Пальпация**

- Костные ориентиры, пространство суставной щели, связки.
- Тепло ладонью (относительное).
- Болезненность: поглаживание, надавливание — «легко» без агрессии.

**Активные движения**

- Сгибание/разгибание, отведение; отметьте боль на каком этапе (начало / середина / конец амплитуды).
- Контралатеральное сравнение.

**Пример OSCE-фразы:** «Правое колено: умеренный синовит, тепло, болезненно при активном сгибании 90°, сравнимо с левым — левое без изменений».

## Что бывает

| Паттерн | Описание для кабинета |
|---------|----------------------|
| Моноартрит | Один сустав: отёк, жар, краснота — срочность по общему состоянию |
| Олиго-/полиартрит | Несколько; симметричность (РА-подобный фенотип) vs асимметрия (ПСА, подагра) |
| Механический артроз | Утренняя скованность <30 мин, крепитация, узелки без выраженного жара |
| Фибромиалгия | Много болезненных точек без объективного отёка — осторожно с формулировкой «воспаление» |
| Периартикулярно | Боль около сустава, а сам сустав нормален — укажите «латеральный эпикондил» и т.п. |
| Поступательное вовлечение | Новые суставы за недели — динамика в тексте |

## Как отметить в кабинете

Свободный текст. Структура:

1. **Какие суставы** (список с сторонами).
2. **Объективные находки:** отёк, цвет, жар, деформация.
3. **Боль:** покой / движение / нагрузка.
4. **Сравнение** с противоположной стороной и с прошлым для пациента.

**Примеры:**
- «Плюснефаланговые 1 справа: припухлость, покраснение, жар, боль при ходьбе; остальные без изменений»
- «Симметрично MCP II–III обе руки: утренний отёк, без яркой гиперемии»
- «Левое колено: выпот по типу «капли», разгибание до 160°, боль при спуске по лестнице»

## Ограничения

- Без УЗИ и пункции нельзя доказать синовит vs обычный отёк.
- Толстая кожа, ожирение маскируют отёк.
- Фотодокументация полезна, но в кабинете — только описание.
- Суставная инфекция у лихорадящего — не терять время на долгий самоопрос.
- Дети: истерические боли без объективных признаков — всё равно описать наблюдение родителя.

## Кратко

Осмотрите и сравните колени, локти, кисти, стопы и другие жалобные суставы: отёк, краснота, жар, форма, боль при сгибании и нагрузке. Перечислите сторону и симметрию. Кратко и по каждому изменённому суставу.
