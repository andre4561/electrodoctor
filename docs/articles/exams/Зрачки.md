# Зрачки

## Что это

Зрачки — центральное отверстие радужной оболочки, регулирующее вход света на сетчатку. В неврологическом и нейрохирургическом осмотре оценивают:

1. **Размер** — диаметр в обычном освещении (норма взрослых примерно 2–4 мм, у детей шире; индивидуальные различия).
2. **Симметрию** — разница **анизокория** > 1 мм при одном освещении подозрительна (но у до 15–20% здоровых — физиологическая анизокория, обычно стабильная годами).
3. **Форму** — круг, овальность, неровность края.
4. **Реакцию на свет** — прямая (на освещённый глаз) и содружественная (на другой глаз).
5. **Аккомодацию** (по возможности) — сужение при переводе взгляда с дали на близкий объект.

Расхождение зрачков (**анизокория**) после **травмы головы**, в сочетании с головной болью, вялостью, рвотой или нарушением зрения — признак, требующий срочной оценки врачом, а не спокойного домашнего наблюдения.

## Подготовка

- Освещение: **умеренное**, одинаковое на оба глаза; не смотреть прямо на яркое окно — зрачки сузятся асимметрично из-за общего засвета.
- Снимите очки; контактные линзы можно оставить, если снятие небезопасно — отметьте в тексте.
- При окрашивающих каплях (миотики, мидриатики), травме глаза, глаукоме — опишите контекст; оценка размера искажена.
- Для проверки света: экран телефона с одной стороны **кратко** (1–2 с), не ослеплять долго; лучше помощник с узким лучом фонарика, направленным на скулу сбоку.
- Сравните с фотографией «в спокойном состоянии», если есть (без вспышки в лицо).

## Как сделать

**Инспекция (без света)**

1. Смотрите в зеркало на расстоянии вытянутой руки; лицо ровно, глаза в одном уровне.
2. Оцените диаметр зрачков: «одинаковые» / «левый крупнее на ~полпалочки».
3. Отметьте форму: круглые, слезовидные, «овальные».

**Реакция на свет (упрощённая)**

1. В полутьме зафиксируйте размер.
2. Свет на **правый** глаз сбоку — правый зрачок сузился? левый (содружественно) тоже?
3. Повторите на **левый**.
4. Медленно уберите свет — зрачки расширяются симметрично?

**Признаки тревоги для записи:**

- Один зрачок широкий и «ленивый» (мало сужается на свет).
- Разная реакция: на одном живее, на другом почти нет.
- Резкая дилатация после удара в голову.

**OSCE-формулировка:** «Pupils equal, round, reactive to light; R 3 mm, L 3 mm; no afferent defect noted» (переводите на русский в кабинете).

## Что бывает

| Наблюдение | Смысл для описания |
|------------|-------------------|
| Равные, симметрично сужаются | Нормальный ориентир на момент осмотра |
| Стабильная лёгкая анизокория без других симптомов | Возможна физиологическая; всё равно зафиксируйте |
| Мидриаз (расширение) одного зрачка, вялая реакция | Очаг III пары, аневризма, внутричерепная гипертензия — срочность по контексту |
| Миоз (сужение) обоих, «точечные» | Опиоиды, холиномиметики, симпатикотония — укажите препараты |
| Зрачки разные + травма | Срочная помощь |
| Один зрачик неровный, «капли» | Иридодиафрагма, прежняя травма глаза |
| Слабое сужение при мигрени | Возможен транзиторный феномен; описать фазу головной боли |

## Как отметить в кабинете

Текст. Минимум:

- Размер/симметрия: «равные ~3 мм» или «R 5 mm, L 2 mm».
- Свет: «PR л» / «реакция на свет сохранена с обеих сторон» / «одностороннее вялое сужение».
- Форма, контекст (травма, капли, головная боль).

**Примеры:**
- «Зрачки равные, круглые, на свет сужаются симметрично»
- «Левый зрачок шире правого, на свет левый почти не сужается»
- «Мелкие равные; без проверки света — темно в комнате»

**Разная величина зрачков после травмы головы** — в тексте явно + срочная помощь.

## Ограничения

- Телефонный фонарик и экран не стандартизируют яркость; сравнение «до/после» у одного наблюдателя надёжнее, чем абсолютные миллиметры без линейки.
- Цвет радужки (тёмный vs голубой) усложняет визуальную оценку.
- Старческая атрофия радужки — неровные края без патологии мозга.
- Фото со вспышкой бесполезно для размера.
- Полноценная оценка афферентного зрачкового дефекта (маргание врача, «swinging flashlight») требует навыка.

## Кратко

В зеркале при ровном свете сравните размер и форму зрачков. Кратко подсветите каждый глаз сбоку: оба ли сужаются. Опишите: равные или нет, живая ли реакция. После травмы головы при разном размере — не откладывайте обращение за помощью.
