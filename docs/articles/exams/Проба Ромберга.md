# Проба Ромберга

Встаньте босиком, пятки вместе, руки вдоль тела. Сначала с открытыми глазами, потом закройте (рядом должна быть опора или человек — риск падения).

Устойчивы / лёгкое покачивание / сильное шатание или падение (куда тянет).

Не делайте, если уже кружится голова или не можете стоять без поддержки.
