# Дорожная карта

## Ближайшее

- [ ] Нормы по полу и возрасту (x0, w зависят от пациента)
- [ ] Маршрутизация по направлениям с мягким отсечением
- [ ] «Следующий вопрос»: незаполненный параметр, сильнее всего разводящий лидирующие диагнозы
- [ ] Список красных флагов по жалобам (не только по анализам)
- [ ] 20–30 частых диагнозов с экспертными весами и источниками

## Средний срок

- [ ] Калибровка весов на открытых данных (MIMIC-IV, NHANES и др.)
- [ ] Учёт коррелирующих показателей (гемоглобин, эритроциты, гематокрит)
- [ ] Составные признаки (сочетания показателей)
- [ ] Динамика показателя между датами
- [ ] Клиент пациента: хранение истории и обезличивание
- [ ] Сервер: API без хранения данных

## Открытые вопросы

1. Как не учитывать коррелирующие анализы трижды?
2. Как выдавать вероятности, если диагнозы не исключают друг друга?
3. Где взять открытые русскоязычные данные «симптом → диагноз»?
4. Как переводить чувствительность и специфичность из статей в веса?
