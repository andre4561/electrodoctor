## 1. Первая версия: что значит «готово» (`docs/v1.md`)

**Цель версии.** Человек вносит свои анализы и базовые данные о себе и получает понятный, объяснимый список из 3–4 вероятных диагнозов. По каждому видно, что повлияло на результат и что досдать.

**Входит в версию 1:**
- [ ] Кабинет: клиент, анкета, анализы по датам, перенос анализов через ИИ (есть)
- [ ] Обязательные поля: пол, возраст, рост, вес (из TODO «Контекст приёма»)
- [ ] Пол и возраст у диагнозов: диагнозы не по полу и возрасту не показываются
- [ ] Выбран один способ силы отклонения (`crit` или `dev`), второй убран или спрятан
- [ ] Подобраны коэффициенты `K`, `NORMAL_LOWER`, `DEFAULT_PRIOR`, `SPEC_*`, и они проверены на эталонных случаях (см. п. 3)
- [ ] Распространённость (`prior`) проверена хотя бы у ? самых частых диагнозов
- [ ] ? Признаки проверены человеком (`checked`) хотя бы у ? диагнозов
- [ ] Эталонные случаи проходят автоматически (`npm test`)
- [ ] Документация описывает кабинет, а не первую версию движка

**Не входит в версию 1 (после):**
- контекст приёма целиком (форма повода обращения, органы и системы)
- исследования (МРТ, КТ, УЗИ, ЭКГ) в истории и в расчёте
- безопасная зона, зависящая от пары «диагноз–показатель»
- учёт коррелирующих анализов, составные признаки, динамика
- калибровка на открытых данных (MIMIC-IV, NHANES)
- серверная часть
- удаление первой версии движка (отдельная задача)

## 3. Эталонные случаи для расчёта кабинета (`tests/cases/`)

Сейчас тесты проверяют только первую версию движка (`parity.test.js`, `test_examples.py`) и статьи (`articles.test.js`). Расчёт кабинета (`src/app/signs.ts`) тестами не покрыт: при подборе коэффициентов не видно, что сломалось.

**Идея:** 10–20 вымышленных пациентов, для каждого — что врач ожидает увидеть.

```json
{
  "name": "Железодефицитная анемия, типичная",
  "patient": { "sex": "F", "age": 34, "labs": { "HGB": 98, "FERRITIN": 6, "MCV": 72 } },
  "expect": {
    "top3_includes": ["Железодефицитная анемия"],
    "not_top10": ["B12-дефицитная анемия"]
  }
}
```

**Какие случаи нужны:**
- типичные: ЖДА, B12-дефицит, гипотиреоз, сахарный диабет 2 типа, метаболический синдром, ?
- пограничные: лёгкое отклонение (ЛПВП 1,1 при норме 1,6 — тот самый случай из TODO)
- «всё в норме» — ни один диагноз не должен быть высоким
- пол и возраст: гинекологический диагноз не появляется у мужчины
- неспецифичный анализ: только высокий СРБ — не должен поднимать десятки диагнозов

Проверки нестрогие («в топ-3», «не выше 10%»), а не точные проценты: тогда коэффициенты можно подбирать, не переписывая тесты каждый раз.

Ожидания должен задавать человек (лучше врач), а не ИИ.
