# Объём движений

Насколько свободно сгибаются и поднимаются руки, шея, ноги, наклоны — по сравнению с «как обычно у вас».

Полный объём без боли — слева; заметное ограничение — середина; почти не двигается сустав — справа. Укажите про себя, какой сустав.
